# Инструкция по сборке и запуску Android-приложения Satva Wellness

Этот каталог `frontend/android` содержит полноценный нативный проект Android, сгенерированный и управляемый с помощью **Capacitor**. Он упаковывает высокотехнологичный React SPA интерфейс платформы Satva Wellness в нативное мобильное приложение.

---

## 🚀 Быстрый старт: запуск и компиляция

### Шаг 1: Требования к окружению
Перед началом убедитесь, что на вашем компьютере установлены:
1. **Node.js** (версии 18+) и npm.
2. **Android Studio** (последняя версия).
3. **Java Development Kit (JDK)** версии 17 (поставляется вместе с Android Studio).

### Шаг 2: Сборка веб-активов React
Перед тем как упаковать приложение в Android, нужно собрать веб-дистрибутив:
```bash
# Из корневой директории проекта или папки frontend
npm run build
```
Это компилирует React SPA в папку `dist/`.

### Шаг 3: Синхронизация кода с Android-проектом
Синхронизируйте собранный веб-код с нативными ресурсами Android-пакета:
```bash
npx cap sync
```
Этот скрипт перенесет весь CSS, JS, HTML и шрифты из папки `dist/` в ассеты Android-приложения.

---

## 🛠️ Разработка и отладка в Android Studio

Вы можете запустить Android Studio с открытым проектом одной командой:
```bash
npx cap open android
```
Это автоматически откроет папку `frontend/android` в Android Studio со всей структурой Gradle.

### Запуск на эмуляторе или физическом устройстве:
1. В Android Studio дождитесь завершения индексации Gradle (процесс Gradle Sync).
2. Подключите физическое Android-устройство по USB (с включенной отладкой USB Debugging в режиме разработчика) или запустите виртуальный эмулятор (AVD Manager).
3. Нажмите кнопку **Run (Зеленый треугольник)** на панели инструментов или нажмите комбинацию клавиш `Shift + F10`.

## 📦 Сборка релизного APK / AAB для Google Play

Для создания готового к дистрибуции установочного файла `.apk` или пакета `.aab` (Android App Bundle) выполните следующие шаги в Android Studio:

1. Перейдите в меню: **Build > Generate Signed Bundle / APK...**
2. Выберите **Android App Bundle** (для Google Play) или **APK** (для ручной установки).
3. Создайте или выберите существующий ключ подписи (Keystore).
4. Установите тип сборки **release**.
5. Нажмите **Finish**. Готовый файл будет сохранен в директории `android/app/release/`.

---

## 🔄 Синхронизация при изменении кода React
Если вы внесли изменения в React-компоненты (`App.jsx`, `api.js` и т.д.):
1. Соберите веб-интерфейс: `npm run build`
2. Перенесите изменения в Android-проект: `npx cap copy`
3. Запустите или обновите приложение на устройстве.
